Privacy policy

This policy explains how this independent, resident-created information website handles visitor information.

Effective August 17, 2026

Information we collect

The site owner does not use accounts, forms, analytics, advertising trackers, or site-set cookies, and does not intentionally collect personal information through this website.

If you contact us by email, the information you choose to send will be used only to respond to your message or maintain this resident resource.

GitHub Pages hosting

This website is hosted by GitHub Pages. GitHub states that visitors' IP addresses are logged and stored for security purposes. That processing is controlled by GitHub and is covered by the GitHub Privacy Statement ↗.

External websites

This site links to government agencies, community organizations, map services, and other third-party websites. Their privacy practices and content are governed by their own policies. Following an external link leaves this website.

Policy updates

This policy may be updated if the site adds new features or changes how information is handled. The effective date above will be revised when material changes are made.
